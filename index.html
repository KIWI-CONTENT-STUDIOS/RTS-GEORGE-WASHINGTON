DEVELOPMENT NOTE

A new campaign begins

This is the first playable foundation, built from scratch with browser-native HTML, CSS, JavaScript and Canvas. No game engine or external assets are needed, so it is quick to run and straightforward to expand.

Every settlement owns its own garrison. Transfers remove troops from the origin while they travel and add them to the destination only on arrival—there is no shared soldier pool. Enemy-held towns with defenders cannot yet be assaulted; tactical battles are a later development phase.

Historical note: The starting map is a simplified, fictionalized campaign setup for playtesting, not a precise representation of control in 1775.
